# AuditFlow — AI Compliance Evidence Manager

AuditFlow is an enterprise SaaS product for collecting, organizing, reviewing, mapping, and exporting compliance-readiness evidence. It is designed for teams preparing for security and privacy readiness work such as SOC 2 readiness, ISO 27001 readiness, GDPR accountability, or internal security audits.

## Current repository status

This repository has been cleaned so active source control contains the product code, product documentation, product tests, and release/operations material only. Historical iteration archives, handoff notes, generated runtime evidence, and iteration-numbered gate scripts have been removed from the active tree.

Runtime acceptance is still **pending** until a real package lockfile exists, dependencies can be installed reproducibly, and the product quality/release workflows run successfully in the target environment. Do not enable customer evidence in production until the production evidence gate and final release approval are both complete.

## Locked product decisions

- Architecture: modular monolith.
- Frontend: React + TypeScript + Vite.
- Backend: Fastify + TypeScript.
- Database: PostgreSQL with Prisma migrations.
- Browser auth: opaque server-side session tokens in HttpOnly cookies plus CSRF protection.
- Tenant isolation: every company-owned operation derives scope from authenticated active membership.
- Evidence readiness: based only on approved, valid evidence versions and approved mappings.
- AI: optional, advisory, structured, provenance-tracked, and human-in-the-loop.

## Main workflows

1. Create a company workspace.
2. Invite members and assign roles.
3. Enable a readiness framework.
4. Manage controls and required evidence.
5. Upload evidence through staged private storage.
6. Review evidence and approve/reject it.
7. Map approved evidence to controls/requirements.
8. Track tasks, comments, dashboards, readiness trace, and reports.
9. Grant time-bounded read-only auditor access when appropriate.
10. Enforce retention, deletion, legal hold, audit logs, and production release controls.

## Local setup

```bash
corepack enable
corepack prepare pnpm@9.12.0 --activate
pnpm install
pnpm db:generate
pnpm db:validate
pnpm typecheck
pnpm test
pnpm build
```

For reproducible CI/release execution, commit a real `pnpm-lock.yaml` generated by pnpm and then use:

```bash
pnpm install --frozen-lockfile
pnpm ci
```

## Important safety rule

This product helps manage evidence and readiness. It must not claim certification, legal compliance, audit success, automatic compliance, or replacement of an auditor/compliance professional.
