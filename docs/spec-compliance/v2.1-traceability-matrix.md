This matrix connects the active product specification to source evidence and verification areas. It intentionally avoids historical pass/archive references.

|---|---|---|---|

| Browser auth uses opaque HttpOnly sessions and CSRF | `backend/src/modules/auth`; cookie and CSRF plugins | auth/RBAC tests | Active |
| Company scope is derived from active membership | company services; tenant context helpers | tenant-boundary/security tests | Active |
| RBAC uses centralized permission predicates and resource scope | permissions/authz modules | permissions and route-contract tests | Active |

| Evidence upload uses staged private storage and finalization | evidence, storage, scan, reconciliation modules | evidence upload/security tests | Active |
| Evidence versions are immutable after approval | evidence services; Prisma schema | evidence review tests | Active |
| Manual mapping review remains separate from evidence review | mapping policy and evidence review modules | mapping/readiness tests | Active |
| Readiness uses approved valid evidence and approved mappings only | readiness calculator; dashboard service | readiness calculator tests | Active |
