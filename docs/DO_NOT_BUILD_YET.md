# Do Not Build Yet

These items are intentionally deferred until the core evidence-management workflow is reliable, tested, and releasable.

## Deferred infrastructure

- Microservices.
- Kubernetes requirement.
- Kafka/event-streaming-first architecture.
- Multiple databases per module.
- Distributed transactions.
- Complex custom permission DSL.

## Deferred product scope

- Payment system.
- Mobile app.
- Real-time chat.
- Official certification claims.
- Automatic compliance claims.
- Autonomous AI agents.

## Deferred enterprise scope

- SSO.
- Large integration marketplace.
- Automated evidence collection from third-party systems.
- Full official framework libraries without legal/licensing review.

Build the core workflow first: authentication, tenant isolation, controls, evidence, review, mapping, readiness, tasks, reports, audit logs, and production release discipline.
