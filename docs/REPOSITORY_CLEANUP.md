# Repository Cleanup

This cleanup removed historical iteration archives, handoff notes, generated runtime evidence, and iteration-numbered gates from active source control.

## Removed from active source

- Root `docs/ITERATION_*.md-style historical files` files.
- Iteration-numbered API contract copies.
- Iteration-numbered exit gates and handoff notes.
- Generated runtime evidence logs, JSON evidence, and manifests.
- Iteration-numbered integrated/static audit scripts.
- Iteration-numbered smoke/runtime scripts.
- Iteration-numbered operations templates after stable copies were created.
- CI/release workflow references to iteration-numbered audit gates.

## Kept or converted

- Product ADRs.
- Locked product specification.
- Production gate source artifacts.
- OpenAPI contract.
- Stable release, migration, monitoring, backup, security, privacy, support, and accessibility templates.
- Product verification scripts that do not depend on historical iteration archives.

## Remaining caution

The repository still needs a real `pnpm-lock.yaml` generated by pnpm before reproducible CI/release execution can be proven with `pnpm install --frozen-lockfile`.
