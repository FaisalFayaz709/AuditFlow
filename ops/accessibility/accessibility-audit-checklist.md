# Accessibility Audit Checklist

Status: BLOCKED until completed.

## Primary workflows

- login/register
- dashboard overview
- controls list/detail
- evidence upload/detail/review
- manual mapping review
- task submission/completion
- report generation/download
- settings/members/framework enablement
- auditor access read-only workflows

## Required checks

- keyboard-only navigation
- visible focus state
- labels on forms and controls
- semantic tables for data grids
- status communicated by text/icon, not color alone
- error messages linked to fields where practical
- destructive actions require confirmation and explain consequences
- auditor read-only UI removes mutation controls
